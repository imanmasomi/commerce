

# Commerce

Commerce is an online auction website built with Django.

## Features

- **User Authentication:** Users can register, log in, and log out.
- **Active Listings:** Users can view all active auction listings.
- **Create Listing:** Signed-in users can create listings with a title, description, starting bid, image URL, and category.
- **Place Bids:** Users can place bids higher than the current bid. Listing owners cannot bid on their own listings.
- **Watchlist:** Users can add listings to or remove listings from their watchlist.
- **Categories:** Users can browse listings by category.
- **Comments:** Users can post comments on listing pages.
- **Close Auctions:** Listing owners can close their auctions.
- **Bid History:** Listing pages display the bids placed on each listing and show the winner when an auction is closed.

## Technologies

- Python
- Django
- HTML
- CSS
- SQLite

## How to Run

1. Open the project directory.
2. Run the following command:

   ```bash
   python manage.py runserver
   ```

3. Open the local development server in your browser.
